# \# منظومة التحليل البيئي لجنوب العراق

# \## Southern Iraq Environmental GIS System

# 

# \*\*المطور:\*\* هيثم حاتم - قسم الجغرافية / جامعة ذي قار - الناصرية

# \*\*التخصص:\*\* نظم المعلومات الجغرافية GIS والاستشعار عن بعد

# \*\*السنة:\*\* 2026

# 

# \### وصف المشروع

# منظومة GIS متكاملة لتحليل التغيرات البيئية في جنوب العراق (6 محافظات) باستخدام بيانات الأقمار الصناعية وGIS.

# 

# \### قاعدة البيانات - 13 طبقة بيئية

# 

# \#### 1. المياه (3 طبقات)

# \- `data/water/rivers.json` - شبكة الأنهار (دجلة، فرات، شط العرب)

# \- `data/water/water-bodies.json` - المسطحات المائية (6 أهوار رئيسية)

# \- `data/water/ponds.json` - البرك والمستنقعات

# 

# \#### 2. الأرض والتضاريس (2 طبقة)

# \- `data/land/dunes.json` - الكثبان الرملية المتحركة

# \- `data/land/land-use.json` - استخدامات الأراضي (5 أصناف)

# 

# \#### 3. المناخ (3 طبقات)

# \- `data/climate/precipitation.json` - معدلات الأمطار 2020-2026

# \- `data/climate/temperature.json` - درجات الحرارة (رقم قياسي 53.2° في البصرة)

# \- `data/climate/drought.json` - مؤشر الجفاف SPI

# 

# \#### 4. الغطاء النباتي (2 طبقة)

# \- `data/vegetation/vegetation.json` - الغطاء النباتي NDVI من Sentinel-2

# \- `data/vegetation/palm.json` - ثروة النخيل (خسارة 60% في البصرة)

# 

# \#### 5. التلوث (1 طبقة)

# \- `data/pollution/pollution.json` - التلوث النفطي والمائي والهوائي

# 

# \#### 6. السكان (1 طبقة)

# \- `data/settlements/settlements.json` - التجمعات السكانية والمخاطر

# 

# \### الإحصائيات

# \- 6 محافظات: البصرة، الناصرية، العمارة، السماوة، الديوانية، الكوت

# \- تغطية: \~140,000 كم2

# \- الفترة: 2020-2026

# 

# \### التقنيات

# \- GIS \& Remote Sensing

# \- JSON Database

# \- Git \& GitHub

# 

# \### الهدف

# توثيق التدهور البيئي: تناقص الأمطار 30%، ارتفاع الحرارة 2-3 درجات، خسارة 60% من النخيل، جفاف الأهوار 75%.
